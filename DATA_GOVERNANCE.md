# Data Governance Status

Wellbeing check-ins, reflections, feedback, conversations, appointments, prescriptions, orders, notifications, and audit records are separate data domains in the current schema.

Member-owned records use owner-scoped access policies. Clinical, pharmacy, generated AI, and operational writes are being moved behind trusted workflows.

Still required for production readiness: granular consent versions, retention/deletion/export workflows, timezone ownership, data classification, provider disclosure, break-glass access, request correlation, privacy-preserving analytics, and a documented backup/restore test.
